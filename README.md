## Coleta de informações

Este aplicativo pode coletar automaticamente algumas informações através de serviços de terceiros, como o Google AdMob, incluindo:

* Identificadores de dispositivo
* Endereço IP
* Dados de uso do aplicativo

## Uso das informações

As informações coletadas são utilizadas para:

* Exibir anúncios relevantes
